# Elimination-compensation pruning: code of the numerical experiments

Code of the numerical experiments of *Progressive elimination-compensation pruning for
real- and complex-valued neural networks*, a development of arXiv:2602.20467. Everything
is written in [JAX](https://github.com/jax-ml/jax).

## Layout

| path | content |
|---|---|
| `ecp/` | the method (small library, see below) |
| `tests/test_formulas.py` | checks of the closed-form expressions against finite differences |
| `experiment.py` | protocol shared by all cases: train, prune, fine-tune, for all methods |
| `datasets.py` | data loaders (MNIST, CIFAR-10, diffusion-sorption) and generator of the synthetic radio signals |
| `case_1_mnist_dense/` | "MNIST": real-valued dense network, classification |
| `case_2_laplace_holomorphic/` | "Laplace": complex-valued semi-holomorphic network, 3D Laplace problem |
| `case_3_cifar_conv/` | "CIFAR-10": real-valued convolutional network, classification |
| `case_4_radio_complex_conv/` | "Radio": complex-valued convolutional network, classification of radio signals |
| `case_5_diffusion_sorption/` | "Diffusion-sorption": real-valued dense network, regression |
| `case_6_cifar_resnet/` | "ResNet-20": ResNet-20 trained with batch normalisation (folded before pruning) on CIFAR-10 |
| `study_*.py` | smaller studies: accuracy of the first-order importance, layer collapse, cost, sensitivity, ... |
| `run_all.sh` | runs the tests and every case and study, one after the other |

The library `ecp`:

| module | content |
|---|---|
| `networks.py` | dense and convolutional layers, real or complex; residual blocks; activations; initialisation |
| `importance.py` | second moments of the sensitivities; importance and optimal bias compensation |
| `compensation.py` | joint compensation of all biases (Gauss-Newton iterations) |
| `procedures.py` | one-shot and progressive elimination-compensation pruning |
| `baselines.py` | magnitude, gradient-magnitude, Wanda, random; brute-force non-linear reference |
| `reconstruction.py` | OBC: layer-wise pruning with reconstruction of the remaining weights |
| `pruning.py` | masks from importances; application of masks and compensations |
| `training.py` | Adam training of (masked) networks |

A network is a list of layer descriptions (`spec`) plus a list of parameter
dictionaries (`params`); a pruning mask is an array of zeros and ones with the shape
of the weights. A minimal example:

```python
import jax
from ecp import networks as nets, importance as imp, pruning

spec = [nets.dense(4, 16, "cprelu"), nets.dense(16, 2)]           # complex-valued network
params = nets.init_params(spec, jax.random.PRNGKey(0), is_complex=True)
x = ...                                                            # samples, shape (N, 4)

second_moments = imp.make_second_moments(imp.output_qoi(spec))     # any architecture
importances, compensations = imp.ec_importance(params, second_moments(params, x))

existing = nets.existing_weights(spec, params)
masks = pruning.global_masks(importances, existing, ratio=0.8)     # remove 80% of the weights
pruned = pruning.apply_masks_and_compensation(params, masks, existing, compensations)
```

## Requirements and data

Python 3.12. `./install.sh` creates the virtual environment `venv/`, installs the packages of `requirements.txt` and runs `tests/test_formulas.py`; `--cpu` installs the CPU-only version of JAX and `--data` downloads MNIST and CIFAR-10 into `data/` (`./download_data.sh`, which `run_all.sh` also calls when they are missing). The datasets are read from
`data/`:

* `data/mnist/` : the four `*-ubyte.gz` files of MNIST;
* `data/cifar10/` : the binary version of CIFAR-10 (`data_batch_1.bin`, ..., `test_batch.bin`);
* `data/diffusion_sorption/1D_diff-sorp_NA_NA.h5` : the diffusion-sorption dataset of PDEBench;
* the radio signals of case 4 and the boundary points of case 2 are generated by the code.

## Running

```bash
python tests/test_formulas.py                 # verification of the formulas (CPU, about 1 minute)
python case_1_mnist_dense/run.py 32 prelu     # one case; results in case_1_mnist_dense/results/
```

`./run_all.sh` runs everything (several hours on a laptop GPU) with the interpreter of `venv/` (created by `./install.sh`) or
the one given by the environment variable `PYTHON`; it stops if a dataset is missing. Each case stores
its results after every seed and resumes from the last completed one if interrupted.
`python case_x/run.py ... --add method_a,method_b` adds methods to stored results.

The jobs need up to 3.5 GB of RAM each. On a machine with little free memory, run them one
at a time inside a memory-capped systemd unit, so that a job that grows too much is
stopped without affecting anything else:

```bash
systemd-run --user --unit=ecp-queue --collect --setenv=PYTHON="$(which python)" \
    -p MemoryMax=3600M -p MemorySwapMax=0 -p OOMScoreAdjust=1000 "$PWD/run_all.sh"
systemctl --user status ecp-queue      # progress is written to logs/queue.log
```

The GPU memory used by JAX is limited to a fixed fraction (`GPU_FRACTION`, default 0.3).

## Scripts and experiments

| experiment | script |
|---|---|
| the five test cases | `case_*/run.py` |
| contribution of joint compensation and progressive pruning (MNIST, Laplace) | `case_1_mnist_dense/run.py 32 prelu ablation`, `case_2_laplace_holomorphic/run.py 32` |
| ranking of the weights within the same progressive procedure (all cases) | `study_ranking.py` |
| MNIST with other networks (appendix) | `case_1_mnist_dense/run.py 64 prelu`, `256 prelu`, `64 tanh` |
| accuracy of the first-order importance; shift without the complementary moments | `study_first_order_accuracy.py` |
| weights kept in each layer (layer collapse on MNIST and Radio; pruned kernel entries of the convolutional networks) | `study_layer_collapse.py mnist`, `cifar`, `radio` |
| cost of training and pruning | `study_epoch_time.py` and the times stored by `case_*/run.py` |
| verification of the closed-form expressions | `tests/test_formulas.py` |
| penalty on the bias shifts of complex networks | `study_regularisation.py` |
| pruning without the complementary moments (Laplace, Radio) | `study_complementary_moments.py` |
| parameters of the progressive procedure | `study_sensitivity.py` |
| single target ratio instead of the path through all the ratios (MNIST) | `study_single_target.py` |
| cheaper settings of the progressive procedure | `study_cost_reduction.py` |
| first-order term of the discrepancy in the importance (MNIST), with two or eight steps between two ratios | `study_residual_term.py`, `study_residual_term.py 8` |
| MNIST with the pixels in [0, 1] (appendix) | `case_1_mnist_dense/run.py 32 prelu --unit-pixels` |
| comparison with OBC and with distillation, OBC followed by the joint compensation or by distillation, and the layer-wise mean correction after magnitude pruning, on the same samples and networks | `study_without_labels.py <case>` |
| other settings of the comparison with OBC and with distillation (MNIST, CIFAR-10, Laplace) | `study_robustness.py <case>` |
| the larger network (ResNet-20) | `case_6_cifar_resnet/run.py`, then `study_without_labels.py resnet` |
| sensitivity of progressive EC to the round-off (MNIST) | `study_roundoff.py` |
| peak GPU memory of training and pruning | `study_memory.py <case> <phase>` |
